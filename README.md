# \# Dialogue System

# 

# Problemi Risolti:

# 1\. ogni volta che schiaccio e ricomincia il dialogo.

# 2\. mancanza di chi sta parlando.

# 

# \## Panoramica

# Questo progetto è stato sviluppato come tesi per il terzo anno. 

# Si tratta di un \[Package per Unity] che si occupa di Tools \& Gameplay con il dialogue system

# trammite un tool per gestire e modificare il dialogo

# 

# \## Caratteristiche

# 

# \- disponibile il tool a grafo per la creazione di collegamenti del dialogo creato.

# \- assegnazione del nome dell'actor e del suo dialogo.

# \- scelta multipla.

# 

# \## Installazione

# 

# 1\. Scarica questa repository come file `.zip` o clonala.

# 2\. Importa tramite il Package Manager usando l'opzione "Add package from disk".

# 3\. Sarà disponibile una scena demo, il dialogue potrà essere.

# iniziato dalla funzione pubblica sia del dialogue system che del UIManager.

# 

# \## Demo Level

# All'interno del pacchetto troverai la cartella DialogueSystemPack

# con all'interno il livello "Demo Scene" che include:

# 1\. introduzione al package.

# 2\. un esempio di gameplaye tra interazione e sequenze di dialoghi.

#

# \## Feedback

# Durante la fase di testing con gli utenti, sono state apportate le seguenti modifiche:

# 1\. sistemate alcune metodiche del dialogue system in modo da far restare il player immobile

# durante il dialogo e a fargli riprendere i comandi alla fine.

# 2\. aggiunta l'opzione di mettere il nome dell'actor del dialogo corrente.

# 3\. aggiunto il singleton per far sì che se ci siano troppe istanze 
dello stesso tipo si rischia l'overflow
